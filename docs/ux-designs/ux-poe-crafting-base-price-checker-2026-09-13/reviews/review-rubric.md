# Spine Pair Review — poe-crafting-base-price-checker

Reviewed: `DESIGN.md` revision 17 and `EXPERIENCE.md` revision 22, against `.memlog.md` rows 239–270, `mockups/key-redesign-dark.html` (v9) and the bmad-ux example spines and `design-md-spec.md`. Review only. No spine, mockup or memlog was edited.

## Overall verdict

The pair is a usable contract. The token sheet is complete, all 528 DESIGN references resolve, and the measured contrast table is correct. Every memlog decision from 239 to 270 is reflected, and no retired element survives as a live rule. A consumer can extract from it cleanly in most places. Before story-dev starts, fix a small set of load-bearing gaps. The committed deploy state (no recipe published) has no header or list treatment. The copy deck is missing strings that the "a string not written here does not ship" rule makes mandatory. Copy placeholders use the token-reference brace syntax. Several facts are written in both spines, and some of those copies already disagree.

## 1. Flow coverage — adequate

Checked: the six PRD journeys (`prd.md` lines 62–67, UJ-1 to UJ-6) against `EXPERIENCE.md` Key Flows. All six exist under the PRD's names, verbatim. Each has numbered steps and a bold **Climax** beat. "The player" is the protagonist by a recorded override (memlog 21). This is accepted. Failure paths exist for UJ-1 (states 26, 28) and UJ-2 (state 25). UJ-5 states its partial support and UJ-6 lands on the honest-empty state.

### Findings
- **medium** UJ-3, UJ-4 and UJ-5 have no failure path, and each has one that applies. UJ-3: the drilled row is a pending or broken crafted row (states 18, 41), so it has no figure to argue for. UJ-4: the stale-patch problem cannot fire (the NOTE FOR ARCHITECT under *Loud when wrong*), so the trust check has to rely on the player's own knowledge of the patch. UJ-5: `sync-report.json` is absent (state 38), or no starvation record matches the current curation, so the alarm the flow depends on does not raise (EXPERIENCE.md 1001–1086). *Fix:* add one `Failure path:` line to each flow that cites the existing state numbers.
- **medium** The flow intro says the flows keep "the PRD's own journey names and substance" (EXPERIENCE.md 938). UJ-2 and UJ-4 now contradict the PRD's current text. PRD UJ-2 says "The control is a number input, not a slider" (prd.md 63), and the spine drags a slider (memlog 255). PRD UJ-4 says "the whole ranking is flagged as resting on the uniform prior" (prd.md 65), and that banner is retired (memlog 256). PRD UJ-1 has the player close the view, and the spine's climax is "he closes nothing".
