Pick-up filter

Shows the bases worth picking up at your threshold of 0.25 div with greater orbs. Your NeverSink filter handles everything else.

  1. Download your NeverSink filter from FilterBlade for offline use, and save it in this folder:
    %UserProfile%\Documents\My Games\Path of Exile 2Copy
  2. Enter that file's name:
    NeverSink's filter 2 - 3-STRICT.filter
  3. Download this filter and save it in the same folder, over the last one. Your browser must ask where to save each download (Settings › Downloads).
    Download crafting-bases.filter
  4. In the game, select crafting-bases once. After each download, reload the filter.
