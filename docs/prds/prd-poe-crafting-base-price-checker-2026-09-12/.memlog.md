- (decision) Item level floor is NOT a single global constant. User's rule: the floor is driven by the item level at which the accepted tier of each tracked modifier becomes available. Accept T1 normally; if T1 requires ilvl 81 or 82 (too rare to be worth chasing), accept T2 instead. The floor for a search is the highest accepted-tier item level among that entry's affixes. Worked example given: bows -> critical hit chance T1 at ilvl>=73, increased physical damage T1 at ilvl 82 (rejected as extremely rare) so T2 at ilvl>=75 -> bow floor is 75. Supersedes the brief's "~78" and the architecture's unresolved "endgame item level" open question.

AD-18 sums T1+T2 weight into one probability while AD-16 prices the same reference by ascending-sort median, which returns T2. EV therefore computes P(T1 union T2) x price(T2); if price(T2) falls below the payout threshold the whole entry truncates to zero and deletes the T1 jackpot mass -- destroying the exact distinction threshold-truncated EV was chosen to provide. AD-17 blocks the naive fix (nested floors are a validation error).
